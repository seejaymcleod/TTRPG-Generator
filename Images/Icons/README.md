# Icons Directory

This directory contains icons used in the application. Make sure the following image files are placed in this directory:

1. `perspective-dice-six-faces-random.png` - Used for reroll buttons
2. `stack.png` - Used for the copy to markdown button
3. `trash-can.png` - Used for the delete card button

If you prefer to use image files instead of Unicode symbols for the collapse/expand arrows:
1. `chevron-down.png` - Down arrow for collapse button
2. `chevron-up.png` - Up arrow for expand button

If the images are still not loading, please try the following:

1. Verify that the files exist in this directory with the exact names
2. Ensure the file names and extensions match exactly (case-sensitive)
3. Restart the server after adding the image files
