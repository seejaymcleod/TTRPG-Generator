## Private Table Packs & Sync

Proprietary, commercial, or third-party copyrighted tables (e.g. *Shadowdark*, *Tome of Adventure*, *Dread Thingonomicon*, *Draw Steel*) are **not** distributed in this open-source repository.

Users may sync their own private or purchased table packs using the built-in **"Sync Tables"** feature via:
1. Connecting a private GitHub repository using a read-only Personal Access Token (stored only locally in the browser's IndexedDB).
2. Local drag-and-drop / file import of personal YAML table files.
